---
title: Switching between Practice and Edit
summary: Jump from a scene in Practice to the same lines in Edit and back, without losing your place or a paused run.
date: 2026-10-07
---

Bigger script changes (reordering, adding lines, timings) belong in Edit. You no longer have to
back out of the scene, change mode and find your place again: the top item of the ⋮ menu swaps
between the two.

## From Practice to Edit

- In Practice, open ⋮ and tap **Edit** (always the top item). The same scene opens in Edit with the
  line you were looking at (the one in the middle of the screen) placed between Edit's small black
  corner markers. It glows for a moment so your eye finds it.
- **Edit** works when the screen is idle or a run is **paused**. Mid-run it is greyed with a short
  reason: "Pause first", "Not mid-run" (during the 3-2-1 countdown or while waiting for Continue),
  or "Exit the Run first" (once a run has finished or been stopped — tap "Exit the Run", then Edit).
  It's also unavailable while a Score Speech run is under way.

## From Edit to Practice

- In Edit, open ⋮ and tap **Run** (always the top item). Practice opens on the line between the
  markers. If that line isn't shown in Practice (for example My Lines Only or Cue-to-cue is on, or
  stage directions are hidden), you land on the nearest shown line before it.
- Back from either screen goes where it always did (the scene list), never to the other mode.

## A paused run waits for you

- If you pause a run and tap **Edit**, the app remembers where the run was. Edit's **Run** item then
  reads "resumes p.N", and tapping it takes you back to Practice, still **paused at that line**,
  however far you scrolled in Edit and however many changes you made.
- Your scores so far stay with the run: lines you've already said keep their accuracy, and the
  end-of-run summary counts them, all as one run in your history. A line whose words you changed in
  Edit shows as not yet attempted (its old score stays in your history); new lines start
  unattempted; deleted lines simply drop out.
- If the line the run was paused on was deleted, the run resumes at the line before it (or the
  nearest earlier line still there, or the first line). A line you moved is found at its new place.
- When you resume, the line starts again from its beginning. Because the speech engines were
  switched off while you were in Edit, you may see "Synthesizing upcoming cues… please wait" before
  the usual 3-2-1, so the run never sits in a silent pause.
- Saved progress (where the scene reopens next time) is not changed by switching.

## Leaving Edit while a run is paused

If a run is waiting and you leave Edit any other way (the back arrow, the Back button or gesture),
the app asks **"Leave your paused run?"**:

- **Back to run** returns to Practice, paused at the remembered line.
- **Abandon run** ends the run and takes you to the scene list. Lines you've already scored are
  kept in your history, just as if you had pressed Stop.
- Tapping outside the box keeps you in Edit with the run still waiting.

Opening Add Line from Edit and coming back doesn't count as leaving. If Android closes the app while
you're in Edit, the paused run is lost but its scores are kept.

> **Tip:** In Line Review, a flagged word's "Edit line" now takes you to Edit at that line too, and
> TalkBack users have "Edit in Edit screen" on every line.
